# موقع MADAR | مَدار

هذا مشروع أولي متكامل لواجهة مَدار، نموذج تقديم طلاب المرحلة الثانوية، ولوحة إدارة خاصة بالطلبات.

## محتويات المشروع
- `index.html`: الموقع العام ونموذج التقديم.
- `admin.html`: صفحة دخول الإدارة ولوحة الطلبات.
- `assets/madar-logo.png`: شعار مَدار المرفق.
- `config.js`: إعداد الاتصال بـ Supabase.
- `schema.sql`: الجداول وسياسات حماية البيانات.
- `app.js` و`admin.js`: وظائف إرسال الطلبات وإدارتها.

## تشغيل الموقع محليًا
يمكن فتح `index.html` مباشرة للمعاينة، لكن إرسال الطلبات ولوحة الإدارة يحتاجان إعداد Supabase.

## ربط قاعدة البيانات
1. أنشئ مشروعًا مستقلًا في Supabase.
2. افتح SQL Editor وانسخ محتوى `schema.sql` ثم نفّذه.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. ضع القيمتين في `config.js`. لا تضع أبدًا `service_role` key في الموقع.
5. من Authentication > Users أنشئ حسابًا لكل مسؤول مصرح له.
6. انسخ UUID لحساب المسؤول من Authentication > Users ثم نفّذ في SQL Editor:
   `insert into public.admins(user_id) values ('UUID-HERE');`
7. افتح `admin.html` وسجّل الدخول بالحساب الذي أضفته.

## النشر
ارفع الملفات إلى GitHub ثم فعّل GitHub Pages من Settings > Pages، أو انشر المجلد على Vercel/Netlify. بعد النشر اختبر إرسال طلب تجريبي، وتأكد أن الزائر لا يستطيع فتح لوحة الإدارة أو قراءة الطلبات.

## ملاحظات مهمة
- لا يوجد حساب مسؤول افتراضي. يجب إنشاء الحساب وإضافته يدويًا.
- لا تضع بيانات دخول Supabase أو `service_role` في ملفات الواجهة.
- اجمع أقل قدر ممكن من بيانات الطلاب، ووضّح لهم سبب جمعها وكيف ستُستخدم.
- بما أن المتقدمين قد يكونون دون 18 عامًا، راجع متطلبات موافقة ولي الأمر وسياسة الخصوصية المناسبة قبل فتح التقديم.
- هذه نسخة تأسيسية؛ قبل الإطلاق العام يُنصح بإضافة سياسة خصوصية منشورة، حماية من الرسائل المزعجة، ورسائل بريدية آمنة لتأكيد الاستلام وتحديث الحالة.


## شروط الأهلية والتقييم
- الأهلية: طلاب الصف الأول أو الثاني أو الثالث الثانوي فقط. لا يوجد شرط عمر إضافي مستقل؛ تاريخ الميلاد يُجمع للتعريف والتحقق من البيانات فقط.
- التقييم المقترح من 100: الدافع 25، التفكير والتعبير 20، الفضول والاهتمامات 20، المبادرة 15، الالتزام 10، التوافق مع قيم مَدار 10.
- التقييم أداة مساعدة لفريق الاختيار وليس قرار قبول آليًا. يجب أن يراجع الفريق الطلبات ويحدد القرار النهائي.
- أضيفت حقول التعريف بالنفس، تاريخ الميلاد، الهاتف الإلزامي، مثال المبادرة، والتفرغ الأسبوعي.
